# serp_events

The underlying `firefox_desktop_derived.serp_events_v2` table and `firefox_desktop.serp_events` view are generated by `sql_generators/serp_events_v2` rather than hand-written SQL, and currently support only Firefox Desktop.

Functions for working with Glean [SERP events](https://dictionary.telemetry.mozilla.org/apps/firefox_desktop?page=1&search=name%3Aserp%20type%3Aevent).
